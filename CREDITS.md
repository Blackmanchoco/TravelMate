# Image credits and intake convention

The machine-readable runtime registry is public/images/credits.json; the public /credits page reads it. Existing detailed licensing/modification notes remain in docs/IMAGE_CREDITS.md. This inventory does not add or relicense any photograph. A local file without a valid matching registry entry must render a placeholder and must not ship as a photo.

For each new supplied/free-licensed image record place, filename, author, source file-page URL, licence and licence URL, actual date accessed, modifications and focal point. No Google, Tripadvisor, Booking, Instagram or Google Places images. Never guess ownership, licence or an access date. A user-supplied photograph needs the user as author plus documented permission/source record. Store locally at public/images/places/<place-slug>.jpg, approximately 1200 px wide, under 300 KB; no hotlinks.
